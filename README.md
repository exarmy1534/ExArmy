# Ex Army Travels 🚖

A modern **Car Rental & Travel Booking Platform** built for **Ex Army Travels**, a Varanasi-based travel service provider. This platform enables users to explore rental vehicles, book rides, and contact the business seamlessly.

## 🌐 Live Website

https://exarmytravels.com

---

## 📌 Project Overview

**Ex Army Travels** is a professional car rental and travel booking website designed to provide:

- 🚕 Car rental services
- 🧳 Travel booking solutions
- 📍 Taxi & cab services in Varanasi
- 🛡️ Reliable and trusted travel experience
- 📞 Easy booking and contact options

The platform focuses on **speed, responsiveness, SEO optimization, and modern UI/UX**.

## 🚀 Installation & Setup

Clone the repository:

```bash
git clone https://github.com/Kartikey-Pathak/Ex-Army-Client-Project.git
```

Move into project directory:

```bash
cd Ex-Army-Client-Project
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```
